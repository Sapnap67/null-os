# Changelog

## 0.2.1 - 2026-08-28

- Unified all cases under a black-and-blue visual identity.
- Added a persistent global light/dark theme toggle.
- Applied theme switching to case selection, desktop, windows, terminal and endings.

## 0.2.0 - 2026-08-28

- Expanded NULL.OS from one story into a three-case mystery anthology.
- Added Case 042 with a frequency puzzle and Case 108 with a sequence puzzle.
- Added case selection, separate saves, distinct themes, commands, passwords and endings.

## 0.1.0 - 2026-08-28

- Added the first complete playable Case 017 story.
- Added boot animation, fake desktop, draggable windows and taskbar shortcuts.
- Added file, mail, terminal, archive and encrypted-vault apps.
- Added five evidence clues, automatic local saving and two endings.
- Added README and Chinese user manual.
